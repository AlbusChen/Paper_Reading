Yan Yang, Xiangru Jian, Ziyang Luo, Zirui Zhao et al. · 2026-07-24
cs.SEcs.CVHF精选computer-use agentsmulti-agent harnessstate groundingverificationmulti-agent
This paper argues that computer-use agents should act on program state rather than relying mainly on screenshots. It introduces StateAct, a code-first multi-agent harness in which a main agent manipulates program state, a GUI subagent handles screenshot-and-click subgoals, independent verification checks final artifacts, and fresh subagents manage long-horizon context. TRACE addresses weaknesses in parametric tool retrieval for enterprise LLMs, where prior training can damage tool knowledge and beam-search decoding is too slow for deployment. It proposes a two-stage curriculum that first seeds tool knowledge and then trains the model to emit reasoning traces before JSON tool-token lists using rule-based and retrieval-relevant data. Characterizing Warp Divergence from Pascal to Blackwell HF Daily
Alpin Dale · 2026-07-26
cs.ARcs.PFHF精选gpu architecturewarp divergenceperformance modelingcompiler analysis
This paper characterizes warp divergence behavior across NVIDIA GPU generations from Pascal through Blackwell. Using microbenchmarks, hardware counters, and SASS analysis, it separates stable performance behavior from changes in compiler-emitted reconvergence mechanisms. The study finds a stable linear serialization cost model for divergent paths across generations, while documenting substantial evolution in control-flow ISA and reconvergence machinery.
中文摘要
该论文刻画了从 Pascal 到 Blackwell 的 NVIDIA GPU 中 warp 分歧行为。作者结合周期级微基准、硬件计数器和编译器生成 SASS 的静态分析，区分稳定的性能规律与重汇合机制的架构变化。研究发现分歧路径的序列化成本在各代 GPU 上保持线性且可预测，但控制流 ISA 和重汇合机制发生了显著演化。
